# Limick

**Keep scrolling. Keep learning.** A social feed where every post is generated from a real public-domain book,
one tap away from the chapter it came from. Built with Flutter and Serverpod for the Serverpod hackathon.

## Run it

1. Add your Anthropic API key to `limick_server/config/passwords.yaml` (this file is gitignored):
   ```yaml
   shared:
     anthropicApiKey: 'sk-ant-...'
   ```
2. In `limick_server`, run `serverpod start`. It starts PostgreSQL (embedded), the server, the background
   library pipeline and the Flutter app.
3. Sign up with email. In development, the verification code is printed in the server log.

The first launch downloads ~78 starter books from Project Gutenberg and starts writing posts. The feed shows a
"Writing your first posts" state until the first batch is ready (usually within a minute).

## Tests

```bash
cd limick_server && dart test
```

No Docker needed: the test database is an embedded PostgreSQL managed by Serverpod.

## AI disclosure

Built with the help of Claude Code. Posts are generated by Claude Haiku 4.5 from the original book text, and
every quote and vocabulary word is checked against that text before it is published.

## Content

All books are in the public domain and come from [Project Gutenberg](https://www.gutenberg.org).
